# 基金工作台

面向手机浏览器的本机基金记录与分析工具，可作为静态站点托管（如 GitHub Pages）。整个应用不需要后端。

## 当前功能

- 总览：基金资产、手动记录的今日收益/持有收益、持仓分布图。
- 持仓：手动新增/编辑基金；可记录申购和赎回；支持从一张截图拆分多只基金的 OCR 草稿，可补录、取消勾选并逐项核对后批量保存。
- 定投：每只基金独立建立、编辑、暂停或删除计划；扣款规则由用户手动设置；默认红利再投资。这里只记录计划，不会下单。
- 数据：本机导入基金历史净值 CSV、导出/恢复 JSON 备份。
- 分析：根据导入净值计算累计回报、年化回报、最大回撤、年化波动率和 Sharpe（假设无风险利率为 0）；支持定投历史回测及历史月收益重抽样的蒙特卡洛情景区间。

## 隐私和数据限制

- 基金、定投、流水和净值保存在当前浏览器的 localStorage。更换设备或浏览器不会自动同步；请定期导出 JSON 并妥善保管。
- 截图通过浏览器内 Tesseract.js 识别，图片不上传。首次使用 OCR 需联网下载 Tesseract.js 和中文语言包；识别是草稿，名称、代码、金额需要逐项核对。当前按文字版面和位置启发式拆分多只基金；复杂截图、换行基金名称或字段错位仍可能误识别，需逐条核对。OCR 不会识别/创建定投。
- 页面没有接入支付宝账户，也不抓取实时行情。当前收益由用户手动录入；净值 CSV 是分析和回测的唯一历史来源。持仓份额可选，导入净值后仅在提供份额时重算估值。
- 回测不含申购费、赎回费、税费、交易确认延迟和节假日扣款细节；每期使用计划日期之后首个可用净值。分红再投资采用 CSV 中的每份分红简化处理。
- 蒙特卡洛按历史月收益有放回抽样，至少需要 25 个不同月份的净值；它不预测真实市场，也不构成收益承诺。
- CSV 应包含 `date,nav,dividend` 或 `日期,单位净值,每份分红` 列。当前仅支持简单逗号/制表符/分号分隔文本，不支持带逗号的引号字段。

## 本地运行

直接打开 `index.html`。页面样式、图表和 OCR 依赖从 CDN 加载，首次打开及 OCR 需网络；离线时本机录入/存储可用，但依赖图表/OCR可能不可用。GitHub Pages 同样是静态托管，不会把 localStorage 数据上传到仓库。

## 开源 UI/图表来源
